# Library Management System Mini Project

## Problem Statement

Managing books manually in libraries can lead to errors in tracking books, members, and fines.

## Proposed Solution

A relational database system that automates:

- Book management
- Member management
- Borrow transactions
- Fine calculation

## Features Implemented

- Entity relationship modeling
- Primary and foreign keys
- Data validation
- Trigger-based automation
- Query optimization using indexes

## Technologies Used

- PostgreSQL
- SQL
- ER Modeling

## Conclusion

This system improves efficiency, reduces errors, and provides faster access to library records.
