# Placement Tracker System

## Problem
Students don't know if they are eligible or likely to get shortlisted.

## Design
We modeled:
- Students
- Companies with eligibility
- Applications
- Interview rounds

## Features
- Tracks applications
- Checks eligibility
- Tracks interview progress

## Sample Results
- Found eligible students using subquery
- Used view for eligibility mapping
- Aggregated shortlisted counts

## Limitations
- No ML prediction
- No resume analysis
- Static CGPA filtering

## Future Work
- Add prediction model
- Resume parsing
- Ranking system
