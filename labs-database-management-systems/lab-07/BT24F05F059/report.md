# Library Management System

## Introduction
The Library Management System is a simple DBMS mini project used to manage books and student records digitally. It helps in storing and retrieving data efficiently.

---

## Problem Statement
Managing library records manually is difficult and time-consuming. This project automates the process of storing student details, book details, and issued books.

---

## Objectives
- Store student records
- Store book records
- Manage issued books
- Perform database queries efficiently

---

## Tables Used

### Students
Stores student information.

### Books
Stores book information.

### IssueBooks
Stores issued book records.

---

## SQL Concepts Used
- Primary Key
- JOIN
- GROUP BY
- Aggregate Functions

---

## Features
- Add students
- Add books
- Issue books
- View records

---

## Sample Queries
- View all students
- View all books
- View issued books
- Count students by course

---

## Conclusion
This project demonstrates the basic concepts of DBMS using SQL and SQLite. It helps understand database creation, insertion, and querying operations.
