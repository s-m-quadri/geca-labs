# College Management System

## Problem
This system manages student enrollments, courses, and faculty.

## Design
We created 4 tables: students, faculty, courses, enrollments.
Relationships are maintained using foreign keys.

## Queries
We implemented joins, grouping, subqueries, and views.

## Output
Queries return student-course mappings, counts, and filtered results.

## Limitations
System does not handle attendance or exams.
