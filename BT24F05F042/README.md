# DBMS Mini Project – College Management System

PRN: BT24F05F042

## Files Included

- ddl.sql → Contains table creation (schema)
- seed.sql → Contains sample data
- queries.sql → Contains SQL queries (joins, subqueries, views)
- schema.md → Explanation of database design
- report.md → Project description and analysis

## Description

This project represents a simple college management system that handles:
- Students
- Faculty
- Courses
- Enrollments

It demonstrates SQL concepts like joins, aggregation, subqueries, and views.
